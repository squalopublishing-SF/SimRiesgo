
# SimRiesgo 2.0

### Free and Open-Source Monte Carlo Simulation and Risk Analysis for Microsoft Excel

**An open-source project by SQUALO & CO.**

**Developed with the assistance of Claude AI by Anthropic.**

SimRiesgo 2.0 is a free, open-source Microsoft Excel add-in designed for Monte Carlo simulation, uncertainty modeling, quantitative risk analysis, and optimization.

The project aims to make advanced simulation and decision-support tools accessible to engineers, researchers, students, educators, and professionals worldwide.

SimRiesgo is openly shared to encourage learning, independent verification, bug fixing, and collaborative software development.

## Key Features

- **Monte Carlo Simulation:** Quantitative uncertainty and risk assessment.
- **Latin Hypercube Sampling:** Stratified sampling for simulation experiments.
- **17 Probability Distributions:** Modeling uncertain input variables.
- **MRG32k3a Random Number Generator:** Advanced pseudorandom number generation.
- **Distribution Fitting:** Statistical distribution fitting using maximum likelihood estimation.
- **Input Correlations:** Rank correlation modeling using the Iman-Conover method.
- **Sensitivity Analysis:** Standardized regression coefficients, Spearman rank correlations, variance contribution, and mean-shift analysis.
- **Scenario Analysis:** Evaluation of outcomes under different conditions.
- **Convergence Analysis:** Assessment of simulation stability.
- **Optimization Under Uncertainty:** Genetic algorithms for exploring decision alternatives.
- **Interactive Results Viewer:** Statistical graphics, probability distributions, scatter plots, scenario comparisons, and data exploration.
