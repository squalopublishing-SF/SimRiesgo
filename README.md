
# SimRiesgo 2.0

### Monte Carlo Simulation and Risk Analysis for Microsoft Excel

**Developed by SQUALO & CO.**

SimRiesgo is a Microsoft Excel add-in designed for quantitative risk analysis, uncertainty modeling, and decision-making through Monte Carlo simulation.

The software integrates simulation, statistical analysis, sensitivity assessment, and optimization capabilities into a familiar spreadsheet environment.

## Key Features

- Monte Carlo simulation and Latin Hypercube Sampling
- 17 probability distributions
- MRG32k3a pseudorandom number generator
- Probability distribution fitting
- Input correlation modeling using the Iman-Conover method
- Sensitivity and scenario analysis
- Simulation convergence assessment
- Optimization under uncertainty using genetic algorithms
- Interactive statistical visualization and reporting

## Applications

SimRiesgo is designed for applications in:

- Engineering and industrial operations
- Project risk assessment
- Financial and investment analysis
- Operations research
- Production and cost uncertainty
- Academic research and education

## Interactive Demonstration

An interactive results viewer will be available to demonstrate the analytical and visualization capabilities of SimRiesgo.
